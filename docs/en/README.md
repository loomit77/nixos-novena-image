# Novena – Universal NixOS SD Image

## Project documentation

This directory contains the English-language documentation for the Novena NixOS SD image project.

The project aims to develop and document a reproducible NixOS SD image for the Kosagi Novena open-hardware computer.

## Documentation status

The original project documentation is maintained in German in the parent `docs/` directory.

English translations will be added incrementally after the corresponding German documents have been reviewed. The German originals remain authoritative if the two versions differ.

## Technical investigation

The project includes investigations into the Novena boot process, U-Boot SPL, DDR initialization, Linux kernel support, device trees, and hardware compatibility.

Experimental observations, confirmed findings, hypotheses, and unresolved questions must remain clearly distinguished.

## References

The project maintains a source register in `docs/QUELLENVERZEICHNIS.md`, including historical documentation and external technical references.

## Contributions

Corrections and contributions are welcome. Technical changes should be supported by reproducible evidence and documented sources.
